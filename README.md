# 📝 Task Tracker CLI

A simple **Command Line Interface (CLI) Task Tracker** built in Python.  
This project is inspired by the [roadmap.sh Task Tracker project](https://roadmap.sh/projects/task-tracker) and is designed to help beginners practice Python, JSON storage, and CLI application development.

---

## 📖 Overview
The Task Tracker lets you:
- Add new tasks
- List all tasks
- Update task descriptions
- Delete tasks
- Mark tasks as `todo`, `in-progress`, or `done`

All tasks are stored in a local `tasks.json` file with timestamps for creation and updates.

---

## ⚙️ Features
- **Add tasks** with descriptions
- **List tasks** with ID, description, and status
- **Update tasks** by ID
- **Delete tasks** by ID
- **Mark tasks** with status (`todo`, `in-progress`, `done`)
- **Persistent storage** using JSON
